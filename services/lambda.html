⚡ AWS Lambda / Amazon API Gateway CLF

AWS Lambda は、サーバーを管理することなくコードを実行できるサーバーレスコンピューティングサービスです。 コードを書いてアップロードするだけで、イベントをトリガーに自動的に実行されます。 Amazon API Gateway と組み合わせることで、スケーラブルなRESTful APIを構築できます。

Lambda の全体像

Lambda の主な特徴

🖥 サーバーレス

サーバーのプロビジョニング・管理が不要。AWSがインフラを全て管理。コードを実行する環境だけを考えればよい。

💰 使用分だけ課金

コードが実行された時間（ミリ秒単位）と呼び出し回数に対して課金。アイドル時間のコストはゼロ。

⚡ イベント駆動

様々なAWSサービスからのイベントをトリガーにして自動実行。S3へのアップロード、DynamoDBの変更、APIリクエストなど。

📊 自動スケーリング

リクエスト数に応じて自動的にスケールアウト。同時実行数の上限（デフォルト1000）まで自動的に並列実行。

Lambda のトリガー（起動元）

🪣 Amazon S3

バケットへのオブジェクトアップロード・削除をトリガーにLambdaを実行。

例：画像アップロード時に自動でサムネイル生成

📊 Amazon DynamoDB Streams

DynamoDBテーブルへのデータ変更（追加・更新・削除）をトリガーに実行。

例：注文データ追加時に通知メール送信

🌐 API Gateway

HTTPリクエストをトリガーにLambdaを実行。REST APIのバックエンドとして利用。

例：GET /users リクエストでユーザーデータを返す

⏰ EventBridge（スケジュール）

Cron式や固定間隔でLambdaを定期実行。

例：毎日0時にバックアップ処理を実行

Lambda の権限管理

🎭 実行ロール（Execution Role）

LambdaがAWSサービスに対して何をできるかを定義するIAMロールです。

  • S3バケットへの読み書き権限
  • DynamoDBテーブルへのアクセス権限
  • CloudWatch Logsへのログ書き込み権限

Lambda関数に必ずアタッチする必要がある

🔑 リソースベースポリシー

誰がLambdaを呼び出せるかを定義するポリシーです。

  • S3がLambdaを呼び出す権限
  • API GatewayがLambdaを呼び出す権限
  • 他のAWSアカウントからの呼び出し許可

Lambda のバージョン管理とエイリアス

概念 説明 変更可否
$LATEST 最新バージョン。デプロイで常に上書きされる。 可変（mutable）
バージョン（番号付き） $LATESTを公開したもの（例：1, 2, 3）。コードと設定が固定される。 不変（immutable）
エイリアス 特定のバージョンへのポインタ（例：prod → v3）。カナリアデプロイ（重み付け）も可能。 指し先を変更可能
エイリアスのカナリアデプロイ
エイリアスは2つのバージョンに重みを付けてトラフィックを分散できます。例：prod エイリアスを「v3: 90%, v4: 10%」に設定してリリース前の検証が可能。

Amazon API Gateway

Amazon API Gateway は、RESTful API・WebSocket API・HTTP API を作成・管理・デプロイするためのフルマネージドサービスです。 Lambda と組み合わせることでサーバーレスAPIバックエンドを構築できます。

🔗 REST API

豊富な機能を持つAPI。認証・認可、APIキー管理、スロットリング、キャッシュなど。本番環境での利用に適している。

⚡ HTTP API

REST APIよりシンプルで安価。Lambda統合とルーティングに特化。低レイテンシで高スループット。

🔄 WebSocket API

双方向リアルタイム通信のためのAPI。チャットアプリ・ライブダッシュボードなどに利用。

サーバーレスアーキテクチャの典型例

🏗 API Gateway + Lambda + DynamoDB パターン
クライアント → API Gateway → Lambda → DynamoDB
（HTTPリクエスト） （ルーティング） （ビジネスロジック） （データ保存）
  • インフラ管理が不要（サーバーレス）
  • 使用分のみ課金（アイドル時のコストなし）
  • 自動スケーリングで高トラフィックにも対応
🔶 試験のポイント（CLF・SAA 頻出）
  • サーバーレス = Lambda（コンピューティング）+ DynamoDB（DB）+ S3（ストレージ）+ API Gateway（API）
  • Lambda の最大実行時間は15分（長時間処理にはECS/EC2が必要）
  • 実行ロール：LambdaがAWSリソースにアクセスする権限
    リソースベースポリシー：誰がLambdaを呼び出せるか
  • $LATEST は可変（mutable）、公開バージョンは不変（immutable）
  • エイリアスでカナリアデプロイ（トラフィック分割）が可能
  • 「S3への画像アップロードを自動処理 → Lambda + S3トリガー」
  • API Gateway + Lambda の組み合わせはサーバーレスAPIの定番パターン
