🔄 AWS DataSync SAA

AWS DataSync は、オンプレミスとAWSストレージ間、またはAWS間でのオンラインデータ移行・同期をサポートするマネージドサービスです。 高速かつ信頼性の高いデータ転送を実現します。

主な特徴

  • 対応ストレージ：S3・EFS・FSx。オンプレミスでは NFS・SMB・HDFS をサポート。
  • 高速・暗号化：ネットワークを最適化し、SSL/TLS で暗号化して安全に転送。接続が途切れても中断箇所から再開できる。
  • メタデータ保持：タイムスタンプ・ディレクトリ構造・アクセス権限など主要なメタデータを保持して移行。
  • 増分同期：移行中に追加・変更されたデータも自動検出して同期。
  • 移行方向：基本は一方向。逆方向の設定を追加すれば双方向同期も可能。
オンプレミスで使用する際は、DataSync エージェントをインストールする必要があります。
🔶 試験のポイント（SAA 頻出）
  • 「オンプレ⇔AWS のオンラインデータ移行・同期 → DataSync」
  • S3・EFS・FSx へ転送。NFS/SMB のファイルサーバー移行に有効
  • オフライン大量移行は Snowball、ゲートウェイ常時接続は Storage Gateway と区別
