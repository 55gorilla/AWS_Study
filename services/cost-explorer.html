💰 AWS Cost Explorer / AWS Budgets CLF

AWSのコスト最適化では、どのサービスにどれだけのコストがかかっているかを把握し、将来のコストを予測することが重要です。 AWS Cost Explorerはコストを可視化・分析するサービス、AWS Budgetsは予算のアラートを設定するサービスです。

AWS Cost Explorer — コスト可視化・分析

AWS Cost Explorerは、AWSリソースの使用量やコストをグラフで可視化し、データを詳細に分析できるサービスです。例えば、EC2やRDSなどのサービスごとに使用状況やコストを詳細に分析し、使用量の変化を時間軸で分析したり、コスト増加の要因を特定するグラフを作成することが可能です。

📊 可視化・分析

過去13ヶ月分のコストデータをグラフで確認できます。デフォルトで用意されているレポートには、よく使われるグラフ構成が含まれており、ユーザーはすぐに分析を始めることができます。

レポートは日次や月次で作成可能で、毎月のコストの推移を確認したり、請求額が高いユーザーを特定して利用状況を見直すなどの分析が行えます。フィルタリング機能を使うことで、サービスごとやアベイラビリティーゾーンごとの料金などより詳細な分析を行うこともできます。

🔮 予測

過去の使用状況を分析し、将来のコストを予測することができます。この機能を活用することで、将来的な予算計画が立てやすくなります。予測の範囲は、1ヶ月後から最大12ヶ月後までです。

コスト配分タグ

コスト配分タグは、AWSリソースのコスト管理と追跡を効率化するための機能です。タグはキーと値から構成され、リソースにタグ付けすることで、コストをプロジェクト、部署、チーム、環境（開発、テスト、本番）などのカテゴリーに分類できます。またAWS Cost Explorerでタグごとのコストレポートを作成できるので、詳細なコスト分析を行えます。

AWS Budgets — 予算アラート

AWS Budgetsは、AWSの各サービスの使用状況を監視し、設定した金額や使用状況のしきい値に近づいたり超えた場合にアラートやアクションを実行するサービスです。アラートはメールやAmazon SNSの通知で受け取ることができます。また、しきい値を超えた時のアクションとして、特定のEC2インスタンス、RDSインスタンスの停止設定なども可能で、これによりさらなるコスト発生を抑制できます。

AWS Pricing Calculator — 事前見積もり

AWS Pricing Calculator（料金見積もりツール）は、AWSの各サービスについて事前にコスト見積もりを行うツールです。必要な設定を入力することで、個々のサービスや複数サービスの組み合わせに基づいた総コストを計算できます。このツールは無料で提供されており、AWSアカウントがなくても利用可能です。例えば、オンプレミス環境からAWSへの移行コストを事前に試算したい場合や、異なるリージョンでのサーバー増加にかかる費用などを見積もりたい時に便利です。

コスト管理サービス比較

サービス主な用途特徴
Cost Explorer 過去コストの可視化・分析・予測 過去13ヶ月分グラフ、将来12ヶ月予測
AWS Budgets 予算設定・超過時アラート メール/SNS通知、EC2/RDS停止アクション
Pricing Calculator 事前コスト見積もり AWSアカウント不要・無料
コスト配分タグ リソース別コスト管理 プロジェクト/部署/環境別のコスト追跡
🔶 試験のポイント（CLF 頻出）
  • 「過去コストを可視化・分析したい → Cost Explorer」
  • 「予算超過をメール通知したい → AWS Budgets」
  • 「移行前のコスト見積もりをしたい → Pricing Calculator」（アカウント不要）
  • Cost Explorerは過去13ヶ月分のデータを参照可能
  • Budgetsはアクションとして「EC2/RDSを停止する」設定も可能
  • コスト配分タグでプロジェクト/部署別コスト管理が可能
