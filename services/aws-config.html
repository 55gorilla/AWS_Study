⚙️ AWS Config SAA

AWS Config は、AWSリソースの設定状態を継続的に記録・監視・評価するサービスです。 「リソースがいつ・どう変更されたか」を追跡し、設定がコンプライアンス基準（ルール）に準拠しているかを自動判定します。

AWS Config の概要

CloudTrailとの違い：CloudTrailは「誰が何の操作をしたか」（API操作の記録）、AWS Configは「リソースが今どういう設定で、過去どう変化したか」（設定状態の記録）。

主な機能

📸 設定の記録・変更追跡

各リソースの設定変更を時系列で記録。「いつ・誰が・どの設定をどう変えたか」を追跡できる。

✅ コンプライアンス評価（Configルール）

ルールを定義してリソースが基準に準拠しているか自動判定。「準拠」「非準拠」を表示。

例：S3バケットが暗号化されているか、必須タグが付いているか

🔔 通知

Amazon SNS / EventBridge と連携して、非準拠を検知したら通知。

🔧 自動修復

Systems Manager Automation と連携して、非準拠リソースを自動的に修正できる。

🔶 試験のポイント（SAA 頻出）
  • 「リソースの設定変更を追跡・コンプライアンス確認 → AWS Config」
  • Config = 設定状態の記録、CloudTrail = API操作の記録（この違いは頻出）
  • Configルールで「準拠/非準拠」を自動判定
  • 非準拠時にSNS通知、Systems Manager Automationで自動修復
  • 「S3バケットが暗号化されているか自動チェック → Config」
