🪪 AWS IAM Identity Center SAA

AWS IAM Identity Center（旧 AWS Single Sign-On）は、複数のAWSアカウントやSaaSアプリへのアクセスを一元管理するサービスです。 一度の認証で複数のアクセス先にログインできるシングルサインオン（SSO）環境を構築できます。

特徴

AWS Organizations と連携することで、組織で管理する複数のAWSアカウントに対するシングルサインオンを実現します。

利用できる認証方式（3つ）
  • IAM Identity Center で管理するユーザー認証情報を使用する
  • SAML 2.0 対応の外部IdP とフェデレーションする
  • AWS Directory Service（オンプレミスの Microsoft Active Directory との連携も可）の認証情報を使用する
🔶 試験のポイント（SAA 頻出）
  • 「複数AWSアカウント／SaaSへのSSOを一元管理 → IAM Identity Center」
  • 旧称は AWS Single Sign-On。Organizations と連携
  • SAML 2.0 外部IdP・Active Directory（Directory Service）と統合できる
