🩻 AWS X-Ray SAA

AWS X-Ray は、アプリケーションの動作データを収集・分析できるサービスです。 主にトラブルシューティング目的で利用され、アプリケーション内のリクエストをトレースして、 処理時間や応答を分析することで、パフォーマンスのボトルネックやエラー発生箇所を特定できます。

特徴

🔍 分散トレーシング

マイクロサービスやサーバーレス構成で、リクエストがどのサービスをどれだけの時間で通過したかを可視化。

🗺 サービスマップ

サービス間の呼び出し関係を地図として表示し、遅延やエラーの発生箇所を直感的に把握。

X-Ray は CloudWatch の「X-Ray トレース」機能としても利用できます。

🔶 試験のポイント（SAA 頻出）
  • 「アプリのボトルネック／エラー箇所を特定したい（分散トレーシング） → AWS X-Ray」
  • Lambda・API Gateway・ECS などマイクロサービスのパフォーマンス分析に有効
  • CloudWatch（メトリクス・ログ）と組み合わせて可観測性を高める
