💾 AWS Backup CLF SAA

AWS Backup は、複数のAWSサービスのバックアップを一元的に管理・自動化するフルマネージドサービスです。 EC2・EBS・RDS・DynamoDB・EFSなど多様なリソースのバックアップを、一つの場所からポリシーで統合管理できます。

AWS Backup の概要

主な機能

🗂 一元管理

EC2・EBS・RDS・DynamoDB・EFS・Storage Gatewayなどのバックアップを統合管理。

📅 バックアップポリシー

スケジュール・保持期間（リテンション）をバックアッププランで自動化。

🌍 リージョン間コピー

バックアップを別リージョンにコピーしてディザスタリカバリ（DR）に対応。

🔶 試験のポイント（CLF・SAA）
  • 「複数サービスのバックアップを一元管理・自動化 → AWS Backup」
  • バックアッププランでスケジュール・保持期間を自動化
  • リージョン間コピーでDR（災害復旧）対応
  • 個別サービスのスナップショット機能をまとめて統合管理できる
