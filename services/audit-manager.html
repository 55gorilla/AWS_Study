🔎 AWS Audit Manager SAA

AWS Audit Manager は、監査の証跡収集を自動化し、コンプライアンス評価を効率化するサービスです。 ISO 27001・SOC 2・PCI DSSなどの規制フレームワークに沿った監査を、リアルタイムで継続的に実施できます。

Audit Manager の概要

手動で行っていた監査用の証跡収集を自動化し、継続的にコンプライアンス状況を評価します。AWS Artifact（既存のレポート取得）に対し、Audit Managerは自社環境の監査証跡を自動収集する点が異なります。

🔶 試験のポイント（SAA）
  • 「監査の証跡収集を自動化・継続的なコンプライアンス評価 → Audit Manager」
  • ISO・SOC・PCI DSS等のフレームワークに対応
  • Artifact（AWSのレポート取得）vs Audit Manager（自社環境の証跡収集自動化）
