🔍 AWS CloudTrail CLF SAA

AWS CloudTrail は、AWS環境内の「いつ」「誰によって（ユーザーやAWSサービス、APIなど）」「どのような操作が行われたのか」を記録・保存するサービスです。利用登録なしに過去90日間のログを無料で参照できます。

CloudTrail のダッシュボード

イベントの発生日時と操作したユーザー、対象のリソース名などが表示されているのがわかります。左端の「▶」マークをクリックすることで、詳細情報を参照することもできます。

例えば、操作した覚えがないのにリソースが増加されていたり、インスタンスが削除されていたような場合でも、CloudTrailのログを参照することで誰がどのような操作を行ったのかを確認できます。

記録対象となるイベント

📋 管理イベント（デフォルト記録）

ユーザーのログイン、AWSリソース自体の作成・変更・削除といった操作（例：EC2インスタンスの作成など）

📄 データイベント（要有効化）

AWSリソースへの細かな操作（例：S3内のデータ操作、Lambda関数の実行など）

🔎 インサイトイベント（要有効化）

通常と異なる操作（例：書き込みAPIの異なる呼び出しなど）

管理イベントはデフォルトで記録されますが、データイベントおよびインサイトイベントはイベントの記録を有効にする必要があります。

証跡情報（Trail）設定

CloudTrailのログは「証跡情報」を設定することでS3バケットに保存できます。これにより90日を超える長期間のログ保存が可能となり、セキュリティ監査やコンプライアンス報告のニーズに対応します。ログはJSON形式で出力され、gz形式で圧縮されてS3に保存されます。Amazon KMSを利用してログデータを暗号化するオプションも提供されています。

🔶 試験のポイント（CLF・SAA 頻出）
  • 「誰がいつどの操作をしたか知りたい → CloudTrail」
  • CloudTrail は90日間無料でログ参照可能（長期保存には証跡情報設定 → S3が必要）
  • 管理イベントはデフォルト記録、データイベント・インサイトイベントは有効化が必要
  • CloudWatch（パフォーマンス監視）とCloudTrail（操作監査）の違いをしっかり区別する
  • CloudTrailのログをCloudWatch Logsに転送し、メトリクスフィルター+アラームで不審操作を通知できる
  • ログはJSON形式でgz圧縮 → S3に保存（KMSで暗号化オプションあり）
