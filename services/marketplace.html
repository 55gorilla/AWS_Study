🛒 AWS Marketplace CLF

AWS Marketplace は、サードパーティ製のソフトウェアやサービスを検索・購入・デプロイできるオンラインストアです。 AMI・SaaS・コンテナ製品・機械学習モデルなどを、AWS利用料金と合算して購入できます。

AWS Marketplace の概要

セキュリティソフト・データベース・開発ツール・OS等のサードパーティ製品を、事前構成済みの形ですぐにデプロイできます。請求はAWSの利用料金に統合されます。

🔶 試験のポイント（CLF）
  • 「サードパーティ製ソフトを購入・デプロイ → AWS Marketplace」
  • AMI・SaaS・コンテナ・MLモデルなどの製品を提供
  • 請求はAWS利用料金と統合され一括管理
  • 事前構成済みで素早くデプロイ可能
