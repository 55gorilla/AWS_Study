🚒 Amazon Data Firehose SAA

Amazon Data Firehose（旧 Kinesis Data Firehose）は、ストリーミングデータを各種データストアへ配信するサービスです。 Amazon S3・Amazon Redshift・Amazon OpenSearch Service などへ送信できます。

仕組み

Data Firehose はプロデューサー（データ送信元）からストリーミングデータを受け取り、 必要に応じてデータ変換処理や Lambda 関数の呼び出しを実行した後、設定された配信先へデータを送信します。 フルマネージドで、スループットに応じて自動的にスケールします。

Kinesis Data Streams との違い

Data FirehoseKinesis Data Streams
役割データストアへの配信（ロード）データの収集・一時保持
管理フルマネージド・自動スケールシャード管理が必要
配信先S3・Redshift・OpenSearch などLambda・Flink などコンシューマーが読み出す
🔶 試験のポイント（SAA 頻出）
  • 「ストリーミングデータを S3 / Redshift / OpenSearch へ簡単に配信 → Data Firehose」
  • 配信前に Lambda でデータ変換できる
  • 収集＝Kinesis Data Streams、配信＝Data Firehose と役割を区別
