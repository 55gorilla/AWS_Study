🌱 AWS Elastic Beanstalk CLF

AWS Elastic Beanstalk は、アプリケーションのコードをアップロードするだけで、インフラを自動構築・管理してくれるPaaS型サービスです。 EC2・ELB・Auto Scalingなどの設定をAWSが自動で行うため、開発者はアプリケーション開発に集中できます。

Elastic Beanstalk の仕組み

開発者がアプリケーションコード（Java・Python・Node.js・PHP・Ruby・.NET等）をアップロードすると、Elastic Beanstalkが裏側でEC2・ELB・Auto Scaling・セキュリティグループ等を自動的にプロビジョニングします。OSやミドルウェアのパッチ適用も自動化されます。

主なメリット

🚀 簡単デプロイ

コードをアップロードするだけ。インフラの知識がなくてもアプリを公開できる。

⚙️ 自動管理

キャパシティのプロビジョニング、負荷分散、Auto Scaling、ヘルスモニタリングを自動化。

🎛 制御も可能

裏側のAWSリソース（EC2インスタンスタイプ等）は必要に応じて自分で設定変更できる。

💰 追加料金なし

Beanstalk自体は無料。作成されたAWSリソース（EC2等）の利用料のみ課金。

CloudFormation / Lightsail との違い

サービス抽象度制御性用途
Lightsail最も高い（簡単）低小規模・シンプルなWebサイト
Elastic Beanstalk高い（PaaS）中Webアプリを素早くデプロイ
CloudFormation低い（IaC）高（細かく制御）複雑なインフラを完全管理
🔶 試験のポイント（CLF・SAA 頻出）
  • 「コードをアップロードするだけでWebアプリをデプロイ → Elastic Beanstalk」
  • PaaS型：インフラ管理不要、開発者はアプリに集中
  • 裏側でEC2・ELB・Auto Scalingを自動構築
  • Beanstalk自体は無料（作成されたリソース分のみ課金）
  • CloudFormationは細かく制御するIaC、Beanstalkは簡単デプロイのPaaS
  • Lightsailはさらにシンプルな小規模向け
