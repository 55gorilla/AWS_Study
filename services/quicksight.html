📊 Amazon QuickSight SAA

Amazon QuickSight は、大規模なデータを分析し可視化するBI（Business Intelligence）サービスです。 様々なデータソースをもとにダッシュボードやレポート、グラフを作成し、データ分析・意思決定を支援します。

特徴

🔌 多様なデータソース

Excel / CSV、Amazon Redshift などのデータベース、S3、Athena、RDS などに接続できる。

📈 ダッシュボード・可視化

グラフやレポートを作成し、インタラクティブなダッシュボードとして共有できる。

⚙️ サーバーレス

フルマネージドでインフラ管理不要。利用量に応じた課金。

🔶 試験のポイント（SAA 頻出）
  • 「データを可視化・ダッシュボード化したい（BI） → Amazon QuickSight」
  • Athena / Redshift / S3 などと連携して分析結果を可視化
