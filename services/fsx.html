📂 Amazon FSx SAA

Amazon FSx は、業界標準のファイルシステムをフルマネージドで提供するサービスです。 EFSがLinux向けのNFSであるのに対し、FSxはWindows環境や高性能コンピューティング（HPC）など、特定のファイルシステム互換性が必要な場合に使用します。

FSx の概要

主な種類

🪟 FSx for Windows File Server

SMBプロトコル対応のWindows向けファイルストレージ。Active Directory統合、Windowsアプリケーションとの完全互換。

用途：Windowsベースの業務アプリ、ファイルサーバー

⚡ FSx for Lustre

オープンソースの高性能ファイルシステム Lustre。機械学習・HPC・ビッグデータ処理などの大規模並列処理に最適。S3と統合可能。

用途：機械学習、HPC、メディア処理

※この他に FSx for NetApp ONTAP、FSx for OpenZFS もあります。

🔶 試験のポイント（SAA 頻出）
  • 「Windows環境でファイル共有（SMB） → FSx for Windows File Server」
  • 「機械学習・HPCの高速ファイルシステム → FSx for Lustre」
  • EFS = Linux向けNFS、FSx for Windows = Windows向けSMB
  • FSx for Windows は Active Directory と統合可能
  • FSx for Lustre は S3 と連携してデータ処理できる
