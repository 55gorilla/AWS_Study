📉 Amazon Redshift SAA

Amazon Redshift は、ペタバイト規模に対応するフルマネージドのデータウェアハウス（DWH）サービスです。 大量のデータに対する集計・分析クエリを高速に実行でき、BI（ビジネスインテリジェンス）や経営判断のためのデータ分析に使われます。

データウェアハウス（DWH）とは

データウェアハウスとは、複数のシステムから収集した大量のデータを統合・蓄積し、分析・レポート用に最適化したデータベースです。通常のRDB（トランザクション処理向け）とは異なり、大規模な集計・分析クエリに特化しています。

Redshift の主な特徴

📊 カラムナー（列指向）ストレージ

データを列単位で保存。集計クエリ（特定列の合計・平均等）が高速。圧縮効率も高くストレージコストを削減。

🚀 ペタバイト規模のスケーラビリティ

複数ノードのクラスター構成で大規模データに対応。MPP（超並列処理）でクエリを分散実行。

🗄 SQL互換

標準SQLでクエリ可能。既存のBIツール（Tableau等）やSQLクライアントから接続できる。

⚡ Redshift Serverless

クラスター管理不要のサーバーレスオプション。クエリに応じて自動スケーリング、使用分のみ課金。

🔶 試験のポイント（SAA 頻出）
  • 「ペタバイト規模のデータ分析・DWH → Amazon Redshift」
  • カラムナー（列指向）ストレージで集計クエリが高速
  • OLAP（分析）はRedshift、OLTP（トランザクション）はRDS/Aurora
  • 標準SQLで分析可能、BIツールと連携
  • Redshift Serverless = クラスター管理不要・自動スケーリング
  • S3のデータを直接クエリする「Redshift Spectrum」もある
