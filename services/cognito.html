👤 Amazon Cognito SAA

Amazon Cognito は、モバイル／Webアプリケーション向けにユーザー認証とアクセス制御を提供するサービスです。 ユーザー名・メール・電話番号でのアカウント作成、パスワード認証に加え、Google や Facebook など外部IDプロバイダー（IdP）による認証も利用できます。数千万ユーザー規模まで対応します。

2つのコンポーネント

🪪 ユーザープール

ユーザーの認証と管理を行う。サインアップ／サインイン／パスワードリセットなどを提供し、外部IdPとのフェデレーション認証にも対応。

認証成功時に JWT（JSON Web Token） を発行し、API Gateway などのアクセス制御に利用できる。

🎫 IDプール（アイデンティティプール）

認証済み／匿名ユーザーに、AWSリソースへアクセスするための一時的な認証情報（STSクレデンシャル）を発行する。

条件に応じて IAM ロールが割り当てられ、そのロールの権限でAWSリソースへのアクセスが制御される。

🔶 試験のポイント（SAA 頻出）
  • 「アプリのユーザー認証・サインイン（数百万人規模）→ Amazon Cognito」
  • ユーザープール＝認証（誰か）、IDプール＝AWSリソースへの一時認証情報
  • Google / Facebook / SAML など外部IdPとのフェデレーションに対応
