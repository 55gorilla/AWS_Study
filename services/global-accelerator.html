🌐 AWS Global Accelerator SAA

AWS Global Accelerator は、ユーザーからAWSリソースまでのアクセス経路を AWSグローバルネットワークを利用して最適化するサービスです。 通常、インターネット経由でAWSリソースへアクセスする際に遅延やパケットロスのリスクがありますが、 Global Accelerator はユーザー近くのエッジロケーションから高速なAWSバックボーン経由でアクセスすることでそのリスクを最小化します。

通常のアクセス vs Global Accelerator 経由

通常のアクセス：パブリックインターネット経由で遅延・パケットロスのリスクあり

Global Accelerator 経由：最寄りエッジ → AWSグローバルネットワーク → リソース

Global Accelerator の機能

🌍 リージョン間の負荷分散

複数リージョンで展開しているWebアプリケーションなどへのリージョン間の負荷分散が可能です。

負荷分散先（エンドポイント）として指定できるもの：

  • ALB（Application Load Balancer）
  • NLB（Network Load Balancer）
  • EC2インスタンス
  • Elastic IPアドレス
❤️ エンドポイントのヘルスチェック

ELBと同様に、Global AcceleratorにもヘルスチェックI機能があります。

ヘルスチェックで異常となったエンドポイントは自動的に負荷分散先から除外され、正常なエンドポイントへトラフィックが転送されます。

📌 固定パブリックIPアドレス

Global Acceleratorは2つの固定パブリックIPアドレス（Anycast IP）を保有します。

  • エンドポイントが変更してもIPアドレスは変わらない → 可用性向上
  • Elastic IPを割り当てられないALBでも固定IPアクセスが可能になる
  • IPアドレスのホワイトリスト管理が容易

固定IP・マルチリージョン構成

CloudFront との違い

比較項目 AWS Global Accelerator Amazon CloudFront
主な用途 TCP/UDP トラフィックの高速化・負荷分散 静的・動的コンテンツのキャッシュ配信（CDN）
プロトコル TCP / UDP（HTTP/S以外も対応） HTTP / HTTPS のみ
キャッシュ なし（高速転送のみ） あり（エッジにコンテンツキャッシュ）
固定IP あり（2つの固定Anycast IP） なし
向いているケース ゲーム・IoT・VoIP・グローバルWebアプリ 静的サイト・動画配信・画像配信
🔶 試験のポイント（SAA 頻出）
  • 「固定IPアドレスでグローバルアクセスを最適化 → Global Accelerator」
  • エンドポイントはALB・NLB・EC2・Elastic IP が指定可能
  • ヘルスチェックで異常なエンドポイントを自動除外 → 高可用性
  • CloudFront との違い：Global Accelerator はキャッシュしない（高速化のみ）、CloudFront はコンテンツをキャッシュ
  • Global Accelerator は TCP/UDP に対応（ゲームサーバー等にも利用可能）
  • ALBには元々Elastic IPを割り当てられないが、Global Accelerator経由で固定IPアクセスが可能になる
