❄️ AWS Snowball CLF SAA

AWS Snowball は、オンプレミス上の大量データを安全に Amazon S3 へ転送するための専用の物理デバイスを提供するサービスです。 AWSから貸し出されたデバイスにデータを取り込み、AWSへ送り返すことでS3に保存されます（オフライン移行）。

特徴

データ量に応じて複数デバイスを併用でき、複数台を「クラスター」として構成すると、負荷分散しながら並行して取り込み、大容量データの移行を効率化できます。クラスター構成で耐障害性・耐久性も高められます。

Snowball の種類

💽 Snowball Edge Storage 最適化

大規模なデータ移行・ストレージ向け。S3へのインポートだけでなくエクスポートにも対応。

🧮 Snowball Edge Compute 最適化

vCPU・メモリを搭載したストレージ一体型。ネットワークが乏しい環境や、データをAWSへ渡す前の処理・分析・機械学習（エッジコンピューティング）に最適。S3/EC2互換APIを提供。

🔶 試験のポイント（CLF / SAA 頻出）
  • 「ネットワークでは時間がかかる大容量データを物理デバイスでオフライン移行 → Snowball」
  • オンライン移行が可能なら DataSync / Storage Gateway を優先。困難な場合の選択肢が Snowball
  • Compute最適化はエッジでの処理・分析・機械学習向け
