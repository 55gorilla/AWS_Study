📑 AWS Artifact CLF

AWS Artifact は、AWSのセキュリティ・コンプライアンス関連の文書をオンデマンドでダウンロードできるサービスです。 ISO・SOC・PCI DSSなどの第三者監査レポートを取得でき、自社の監査やコンプライアンス対応に活用できます。

AWS Artifact の概要

🔶 試験のポイント（CLF）
  • 「AWSのコンプライアンス監査レポートを取得 → AWS Artifact」
  • ISO 27001・SOC 2・PCI DSSなどの第三者監査レポートをダウンロード可能
  • 自社の監査・コンプライアンス対応の証跡として利用
  • 無料で利用可能
