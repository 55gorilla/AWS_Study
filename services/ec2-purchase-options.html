🖥 EC2 インスタンスの購入オプション CLF

Amazon EC2 には複数の購入オプションがあり、ワークロードの特性（予測可能性・コスト優先・専有要件など）に応じて最適な選択ができます。 CLF・SAA ともに頻出の比較問題です。各オプションの特徴と使いどころを正確に把握しましょう。

購入オプション全体像

購入オプション詳細

📌 オンデマンドインスタンス（On-Demand）
使った分だけ支払い。コミットメントなし。
特徴
  • 秒単位または時間単位の課金
  • 前払い不要・長期コミットなし
  • 最も高い単価
向いているワークロード
  • 需要が不規則で予測できない
  • 短期間の開発・テスト環境
  • 中断できないアプリケーション
🔖 リザーブドインスタンス（RI: Reserved Instances）
1年または3年のコミットメントで最大72%割引。
スタンダードRI
特定のインスタンスファミリー・リージョンに固定。最大72%割引。未使用分は RIマーケットプレイスで売却可能。
コンバーティブルRI
インスタンスファミリー・OS・テナンシーを変更可能。最大66%割引。売却は不可。
支払いオプション（割引率：全前払い ＞ 一部前払い ＞ 前払いなし）
  • All Upfront（全額前払い）: 最大割引
  • Partial Upfront（一部前払い）: 中間割引
  • No Upfront（前払いなし）: 最小割引
💰 Savings Plans
時間当たりの使用量をコミットすることで割引を受けるモデル。RIより柔軟。
Compute Savings Plans
最も柔軟。EC2・Lambda・Fargateに適用。インスタンスファミリー・リージョン・OS・テナンシーを問わず有効。最大66%割引。
EC2 Instance Savings Plans
特定のリージョン・インスタンスファミリーにコミット。AZ・OS・サイズは柔軟。最大72%割引。
⚡ スポットインスタンス（Spot）
AWSの余剰キャパシティを最大90%割引で利用。ただし中断リスクあり。
特徴
  • 最大90%割引（最も安い）
  • AWSの都合で2分前通知で中断される可能性
  • スポット価格は需要に応じて変動
向いているワークロード
  • バッチ処理・データ分析
  • 画像・動画変換
  • 中断可能な分散ワークロード
  • CI/CDパイプライン
🏠 Dedicated Instances（専有インスタンス）
物理ホストが他のAWSアカウントと共有されない。
  • 物理ハードウェアは専有だが、同一アカウントの他インスタンスと共有する場合がある
  • インスタンスの物理ホストへの配置はAWSが管理
  • コンプライアンス要件（他社との物理共有禁止）に対応
🏗 Dedicated Hosts（専有ホスト）
物理サーバー全体を専有。インスタンス配置を完全に制御できる。
  • 物理サーバーを丸ごと占有（最も高コスト）
  • ソケット数・コア数・ホストIDが見えるため BYOL（ライセンス持込）に対応
  • Windows Server / SQL Server / Oracle などのライセンス管理が必要な場合に使用
  • Dedicated Instances との違い：インスタンス配置を自分でコントロールできる点

RIマーケットプレイス

🛒 Reserved Instance Marketplace

不要になったスタンダードRIを他のAWSユーザーに売却できるマーケットプレイスです。
コンバーティブルRIは売却できません（変換という別のオプションが用意されている）。

🔶 試験のポイント（CLF・SAA 頻出）
  • 最も安い = スポット（最大90%）、ただし中断される可能性あり
  • BYOL（ライセンス持込）が必要 → Dedicated Hosts
  • RI とSavings Plans の割引率は同程度だが、Savings Plans の方が柔軟
  • コンバーティブルRI は売却不可、スタンダードRI は RIマーケットプレイスで売却可能
  • Dedicated Instances と Dedicated Hosts の違い：ホスト配置の制御権があるかどうか
  • 「長期的に安定した予測可能なワークロード → RI または Savings Plans」
  • 「需要が変動する・短期 → オンデマンド」
