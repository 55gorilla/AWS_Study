🏛 AWS Control Tower SAA

AWS Control Tower は、セキュアなマルチアカウント環境を自動的にセットアップ・管理するサービスです。 Organizations・Config・CloudFormationなどを組み合わせ、ベストプラクティスに沿った「ランディングゾーン」を簡単に構築します。

Control Tower の概要

複数のAWSアカウントを使う組織で、ガードレール（予防的・発見的統制）を自動適用し、ガバナンスを効かせた環境を素早く立ち上げられます。

🔶 試験のポイント（SAA）
  • 「セキュアなマルチアカウント環境を自動構築 → Control Tower」
  • ランディングゾーンを自動セットアップ（Organizations + Config + CloudFormation）
  • ガードレールでガバナンスを自動適用
  • Organizations（アカウント管理の基盤）の上位で、ベストプラクティスを自動化
