🔗 Amazon VPC CLF SAA

Amazon VPC（Virtual Private Cloud）は、AWS内に独立したプライベートネットワーク空間を作成するサービスです。 EC2・RDSなどのリソースをVPC内に配置し、外部からのアクセスを細かく制御できます。SAA試験で最も重要なサービスの一つです。

サブネット（パブリック vs プライベート）

種類インターネット接続配置するリソース例
パブリックサブネット ◎ インターネットゲートウェイ経由で双方向接続 WebサーバーEC2、ALB、踏み台サーバー
プライベートサブネット △ NATゲートウェイ経由でアウトバウンドのみ可 DBサーバー、アプリサーバー（外部に直接さらさない）

IPアドレスの種類

🏠 プライベートIPアドレス

VPC内部でのみ使用。インスタンス起動時に自動割り当て。インスタンスを停止しても変わらない。

🌐 パブリックIPアドレス

インターネット接続用の動的IP。インスタンスを停止・再起動するたびに変わる。

📌 Elastic IPアドレス

固定のパブリックIPアドレス。インスタンスを停止・再起動しても変わらない。アタッチしていない間は課金発生。

インターネットゲートウェイ / NATゲートウェイ

🌐 インターネットゲートウェイ（IGW）

VPCとインターネット間の双方向通信を可能にするゲートウェイ。パブリックサブネットのルートテーブルにIGWへのルートを設定することで、インターネット接続が有効になります。

🔄 NATゲートウェイ

プライベートサブネットのリソースがインターネットへアウトバウンド通信のみできるようにするサービス。外部からの直接アクセスは不可。パブリックサブネットに配置。AWSマネージドサービス（可用性高）。

セキュリティグループ vs ネットワークACL

比較項目セキュリティグループ（SG）ネットワークACL（NACL）
適用範囲EC2インスタンス単位サブネット単位
ステートフル / ステートレスステートフル（インバウンドを許可すれば応答は自動許可）ステートレス（インバウンド・アウトバウンド両方の定義が必要）
ルールの評価全ルールを評価して最終判断番号順に評価（最初にマッチしたルールが適用）
デフォルト動作全て拒否（明示的許可が必要）デフォルトNACLは全て許可
Deny設定不可（許可のみ）可（許可/拒否を設定できる）
多層防御のベストプラクティス：セキュリティグループ（インスタンス単位）+ NACL（サブネット単位）の組み合わせで多層のネットワークセキュリティを実現

VPCエンドポイント（AWS PrivateLink）

VPC内のリソースがインターネットを経由せずにAWSサービスに接続できる仕組みです。プライベートサブネットのEC2がインターネットなしにS3やDynamoDBにアクセスするケースで使用します。

🚪 ゲートウェイエンドポイント

S3とDynamoDB専用。ルートテーブルにエントリを追加するだけ。無料。

🔌 インターフェースエンドポイント（PrivateLink）

その他のAWSサービス向け。ENI（Elastic Network Interface）をサブネットに作成。有料。

VPC間の接続

🤝 VPCピアリング

2つのVPC間をプライベートに接続。インターネット経由しない。ただし推移的接続は不可（A↔B↔CでもA↔C不可）。接続数が増えると管理複雑。

🌐 AWS Transit Gateway

複数VPCやオンプレミスをハブアンドスポーク型で接続する中央ルーター。推移的接続が可能。大規模な複数VPC環境に最適。

VPCフローログ

VPC内のネットワークインターフェースを通過するIPトラフィックの情報を記録するサービスです。セキュリティ分析・トラブルシューティングに使用します。CloudWatch LogsまたはS3に保存できます。

AWS Network Firewall

VPCのトラフィックを深いパケット検査（DPI）でフィルタリングする高度なファイアウォールサービスです。セキュリティグループ・NACLより高度なL7レベルの制御が可能です。

🔶 試験のポイント（CLF・SAA 最重要）
  • セキュリティグループはステートフル（応答は自動許可）、NACLはステートレス（両方向の定義必要）
  • パブリックサブネット → インターネットゲートウェイ（双方向）
  • プライベートサブネット → NATゲートウェイ（アウトバウンドのみ）
  • Elastic IP = 固定パブリックIP（インスタンス停止後も保持）
  • VPCエンドポイント：インターネット経由せずにS3/DynamoDBに接続（ゲートウェイ型が多い）
  • VPCピアリングは推移的接続不可。多数のVPC接続にはTransit Gatewayを使う
  • NACLはサブネット単位、セキュリティグループはインスタンス単位
  • 「プライベートサブネットのEC2がインターネットにアクセス → NATゲートウェイ」
