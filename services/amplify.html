🔺 AWS Amplify SAA

AWS Amplify は、Web／モバイルアプリをAWS上で構築・公開するためのフルスタック開発プラットフォームです。 認証・データベース・ストレージなどのバックエンド機能に加え、ホスティングやCI/CDの仕組みも一括で提供します。

特徴

🧩 バックエンド一括構築

認証（Cognito）・API・データベース・ストレージなどをマネージドサービスと連携して簡単に構築。

🚀 ホスティング & CI/CD

静的サイトやSPAのホスティング、Gitと連携した自動ビルド・デプロイを提供。

⚛️ フロントエンド連携

React や Next.js などのフレームワークから簡単に組み込める。

バックエンド開発を簡素化し、本質的な機能開発に集中して、より早くサービスをリリースできます。

🔶 試験のポイント
  • 「Web/モバイルアプリのフロント＋バックを素早く構築・ホスティング → Amplify」
  • 認証は Cognito、ホスティングはCDN配信、CI/CDも統合
