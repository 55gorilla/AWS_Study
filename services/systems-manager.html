🛠 AWS Systems Manager SAA

AWS Systems Manager（SSM）は、複数のAWSリソース（EC2やオンプレミスサーバー）を一元的に管理・運用するためのサービス群です。 OSパッチ適用、設定値の管理、運用タスクの自動化などをまとめて行えます。

主な機能

🩹 Patch Manager（パッチ管理）

EC2やオンプレミスサーバーのOSパッチ適用を自動化。パッチベースラインを定義して一括適用。

📋 Parameter Store（パラメータストア）

設定値・環境変数・パスワードなどを安全に保管。SecureStringで暗号化も可能。標準利用は無料。

🤖 Automation（自動化）

運用タスクをランブック（手順書）として定義し自動実行。AWS Configと連携して非準拠リソースの自動修復も可能。

💻 Session Manager

SSHキーや踏み台サーバーなしでEC2に安全に接続。操作ログも記録され監査に有用。

利用には対象リソースに SSM Agent がインストールされている必要があります（Amazon Linux等には標準でプリインストール）。
🔶 試験のポイント（SAA 頻出）
  • 「複数EC2のOSパッチを一括管理 → Systems Manager（Patch Manager）」
  • 「設定値・環境変数を安全に保管（無料） → Parameter Store」
  • 「SSHキーなしでEC2に安全接続 → Session Manager」
  • Automation で運用タスクを自動化、Config と連携して自動修復
  • Parameter Store（無料・設定値）と Secrets Manager（有料・自動ローテーション）の使い分け
  • SSM Agent が対象リソースに必要
