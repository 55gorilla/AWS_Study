🛡 セキュリティ検出サービス CLF SAA

AWSには、脅威の検出・脆弱性評価・機密データ検出・統合管理を担う複数のセキュリティサービスがあります。 ここでは Amazon Macie / GuardDuty / Inspector / Security Hub を比較します。

4サービスの役割

🔍 Amazon Macie

S3バケット内の機密データの検出・分類に特化。機械学習とパターンマッチングで、個人情報（PII：氏名・住所・電話番号・クレジットカード番号など）を識別・分類する。

🐶 Amazon GuardDuty

AWS環境全体の脅威検出サービス。アカウント・ワークロード・データへの不正なアクティビティ（マルウェア・フィッシング・データ盗難など）を継続的に監視する。

🩺 Amazon Inspector

EC2やコンテナなどリソース・アプリの脆弱性評価。CVEデータベースを基にルールを定期更新し、ベストプラクティスやコンプライアンス準拠を評価する。

🗂 Amazon Security Hub

各種セキュリティサービス（サードパーティ含む）のアラートやデータを自動収集・一元管理。業界標準のベストプラクティスや規制要件への準拠状況を評価する。

使い分けの早見表

サービス対象目的
MacieS3 のデータ機密データ（PII）の検出・分類
GuardDutyアカウント・ログ・ネットワーク脅威・不正アクティビティの検出
InspectorEC2・コンテナ・アプリ脆弱性の評価・診断
Security Hub各種セキュリティサービス全体アラートの統合・一元管理
🔶 試験のポイント（CLF / SAA 頻出）
  • 「S3の機密データを見つけたい → Macie」
  • 「不正アクセス・脅威を検知したい → GuardDuty」
  • 「脆弱性をスキャンしたい → Inspector」
  • 「複数のセキュリティ結果を一元管理したい → Security Hub」
