💻 AWS Cloud9 SAA

AWS Cloud9 は、AWSが提供するクラウド型の統合開発環境（IDE）です。 IDEとは、コードの記述・実行・デバッグを統合した開発ツールで、Cloud9 はこれらをブラウザ上で利用できます。

特徴

🌐 ブラウザだけで開発

ローカルに開発用ソフトをインストールせず、ブラウザから開発できる。

👥 共同編集

チームでコードを編集しながらチャットでやり取りでき、共同作業が効率的。

🧑‍💻 多言語対応

JavaScript・Python・PHP など主要な言語に対応。

⚡ Lambda連携

AWS Lambda と連携し、サーバーレスアプリの開発・デバッグができる。

🔶 試験のポイント
  • 「ブラウザで使えるクラウドIDE → AWS Cloud9」
  • チームでの共同編集、Lambda のサーバーレス開発に有効
