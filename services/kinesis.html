🌊 Amazon Kinesis SAA

Amazon Kinesis は、ストリーミングデータをリアルタイムで収集・処理するサービスです。 ストリーミングデータとは継続的に生成されるデータのことで、IoTデータ・株取引情報・オンラインゲームのユーザーデータなどが該当します。 Kinesisでは受け取ったストリーミングデータを他のAWSサービスと連携してサンプリングや分析などができます。

ストリーム処理 vs バッチ処理

🌊 ストリーム処理

継続的に生成されるデータに対してリアルタイムで処理を行う方式。データが届いた瞬間に処理が走る。

例：IoTセンサーの異常検知、リアルタイム不正検知、ライブダッシュボード更新

📦 バッチ処理

まとまったデータに対して一括で処理を行う方式。定期的に実行される。

例：日次・週次・月次の集計処理。特定期間のデータに対して定期的に実行。

多くの企業ではストリーム処理とバッチ処理の両方を用いてシステムを構築し、柔軟なデータ処理を行っています。

Amazon Kinesis Data Streams

Amazon Kinesis Data Streams は、IoTセンサーなど外部から送信されるストリーミングデータを収集するサービスです。 Kinesis Data Streams が収集したストリーミングデータを、他のサービス（例：Lambda、Data Firehose、Managed Service for Apache Flink）が読み込んで、データ変換や分析などの処理を行います。 なお、収集したデータは一定期間（デフォルトで24時間、最長で1年）保持できます。

プロデューサーとコンシューマー
Kinesisでは、ストリーミングデータを生成し送信するデバイスやサービスなどを「プロデューサー」、ストリーミングデータを読み出して処理する役を「コンシューマー」と呼びます。
📤 プロデューサー（生産者）

ストリーミングデータを生成してKinesisへ送信するもの

  • IoTセンサー・デバイス
  • Webサーバーのアクセスログ
  • モバイルアプリのクリックストリーム
  • 金融取引データ
📥 コンシューマー（消費者）

Kinesisからデータを読み出して処理するもの

  • AWS Lambda — サーバーレスで即時処理
  • Kinesis Data Firehose — S3/Redshiftへ配信
  • Managed Service for Apache Flink — リアルタイム分析

Amazon Kinesis Video Streams

Amazon Kinesis Video Streams は、カメラやその他のデバイスからリアルタイムで動画データを取り込むサービスです。 取り込んだ動画データは、他のAWSサービスと統合して、解析や加工、再生などに利用できます。

📹 主な活用シーン
  • 防犯カメラ映像のリアルタイム監視
  • スマートホームデバイスの動画ストリーミング
  • 工場の生産ラインの品質監視
  • ライブストリーミング配信
🔗 連携サービス
  • Amazon Rekognition — AI による顔認識・物体検出
  • Amazon SageMaker — 機械学習モデルで動画分析
  • Amazon S3 — 動画データの長期保存

Kinesis ファミリーまとめ

サービス名 役割 主な用途
Kinesis Data Streams ストリーミングデータを収集・一時保持 IoT・ログ・クリックストリームの収集
Kinesis Data Firehose ストリームデータをデータストアへ配信 S3・Redshift・OpenSearchへのデータ転送
Managed Service for Apache Flink ストリームデータのリアルタイム分析 リアルタイム集計・異常検知・変換
Kinesis Video Streams 動画データをリアルタイムで収集 監視カメラ・スマートデバイス動画処理
🔶 試験のポイント（SAA 頻出）
  • 「IoTデータをリアルタイムで収集・処理 → Amazon Kinesis」
  • Kinesis Data Streams のデータ保持期間：デフォルト24時間、最長1年
  • プロデューサー（生産者）がデータを送信し、コンシューマー（消費者）が読み出して処理
  • コンシューマーとして Lambda・Data Firehose・Flink が使える
  • Kinesis Video Streams は動画データ専用
  • バッチ処理との違い：ストリーム処理はリアルタイム（継続的）、バッチは一括定期実行
  • 「数百万のデバイスから毎秒データを収集してリアルタイム分析 → Kinesis」
