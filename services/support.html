🛟 AWS サポートプラン CLF SAA

AWSサポートは、技術的な問題の解決や運用支援を提供するサービスです。 サポートプランはベーシック／開発者／ビジネス／エンタープライズ On-Ramp／エンタープライズの5種類があります。

5つのサポートプラン

プラン対象主な内容
ベーシック全ユーザー（無料）ドキュメント・FAQ・フォーラム・一部のTrusted Advisor。技術問い合わせは不可。
開発者（デベロッパー）個人・小規模チーム（有料）技術担当者へ Web フォーム（メール）で問い合わせ可能。
ビジネス業務利用の企業（有料）Web・電話・チャットで 24時間365日。Trusted Advisor 全機能、Health API。
エンタープライズ On-Rampビジネスとエンタープライズの中間24/365 問い合わせ、全Trusted Advisor／Health API。年1回の Countdown 支援。
エンタープライズ大規模環境（最上級）24/365、専任TAM、コンシェルジュ（請求/アカウント）、Countdown など。

関連する仕組み

🗂 AWS サポートセンター

マネジメントコンソールから技術／請求の問い合わせを「ケース」として登録するプラットフォーム。

🔧 AWS サポート API

サポートケースの作成・更新・進捗確認をプログラムで自動化。ビジネス以上のプランで利用可。

👷 AWS プロフェッショナルサービス

AWSの専門チームによるプロジェクトベースのコンサルティング・構築支援。

💬 AWS re:Post / ナレッジセンター

コミュニティ主導のQ&Aサービス（無料）と、AWS公式の記事・動画集。

🔶 試験のポイント（CLF 頻出）
  • 5プラン：ベーシック / 開発者 / ビジネス / エンタープライズ On-Ramp / エンタープライズ
  • 24時間365日の電話・チャット問い合わせはビジネス以上
  • Trusted Advisor 全機能はビジネス以上、ベーシック／開発者は一部のみ
  • 専任TAM・コンシェルジュはエンタープライズ
