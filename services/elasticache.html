⚡ Amazon ElastiCache SAA

Amazon ElastiCache は、メモリ上にデータを保持するフルマネージドのインメモリキャッシュサービスです。 データベースへのクエリ結果などをメモリにキャッシュすることで、超高速なレスポンス（マイクロ秒〜ミリ秒）とデータベース負荷の軽減を実現します。

インメモリキャッシュの仕組み

graph LR App[アプリケーション] -->|1. キャッシュ確認| Cache[(ElastiCache\nメモリ上)] Cache -->|2a. ヒット\n超高速応答| App Cache -.->|2b. ミス| DB[(RDS / Aurora\nディスク)] DB -.->|3. 結果取得| App App -.->|4. キャッシュに保存| Cache style Cache fill:#00B3A7,color:#16191F style DB fill:#008A81,color:white

アプリケーションはまずElastiCacheを確認し、データがあれば（キャッシュヒット）即座に返します。なければ（キャッシュミス）データベースから取得し、次回のためにキャッシュに保存します。

2つのエンジン

🔴 Redis（推奨）
  • 高度なデータ構造（リスト、セット、ソート済みセット）
  • レプリケーション・自動フェイルオーバー対応（高可用性）
  • データの永続化が可能
  • Pub/Sub メッセージング
🟢 Memcached
  • シンプルなキーバリューキャッシュ
  • マルチスレッドで高スループット
  • 水平スケーリングが容易
  • 永続化・レプリケーションは非対応
🔶 試験のポイント（SAA 頻出）
  • 「DBの読み取り負荷を軽減・高速化 → ElastiCache」
  • インメモリ（RAM）のためマイクロ秒〜ミリ秒の超低レイテンシ
  • Redis = 高機能（永続化・レプリケーション・HA）、Memcached = シンプル・高速
  • 「高可用性・データ永続化が必要 → Redis」「シンプルなキャッシュ → Memcached」
  • セッション管理・リーダーボード・リアルタイムランキングにも利用
  • DynamoDBの前段キャッシュには DAX（DynamoDB Accelerator）もある
