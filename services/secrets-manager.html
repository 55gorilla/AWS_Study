🔒 AWS Secrets Manager SAA

AWS Secrets Manager は、データベースのパスワード・APIキー・アクセスキーなどの機密情報（シークレット）を安全に保管・管理するサービスです。 ソースコードへのハードコーディングを排除し、認証情報を一元管理できます。

Secrets Manager の概要

ハードコーディングの問題：パスワードをコードに直接書くと、漏洩リスクが高く、変更のたびにコード修正が必要になります。Secrets Managerはこれを解決し、アプリケーションは実行時にAPIで安全に認証情報を取得します。

主な機能

🔐 安全な保管

機密情報をAWS KMSで暗号化して保管。IAMポリシーでアクセス制御。

🔄 自動ローテーション

Lambda関数を使って、パスワードなどを定期的に自動更新。RDS・Redshift・DocumentDBには組み込みのローテーション機能あり。

🔗 サービス統合

RDS・Redshiftなどと統合。アプリケーションはAPIで最新の認証情報を取得。

📋 監査

CloudTrailと連携してシークレットへのアクセスを記録・監査。
