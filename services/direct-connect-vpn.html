🔌 AWS Direct Connect / AWS VPN CLF SAA

オンプレミスからAWSへ接続する際、通常のインターネット回線には傍受や改ざんのリスクがあります。 このリスクを軽減し、AWSへセキュアに接続するサービスが「AWS Direct Connect」と「AWS VPN」です。

AWS Direct Connect（DX）

AWS Direct Connect は、オンプレミスからAWSへ専用回線を使ってセキュアに接続するサービスです。 インターネット回線ではなく専用回線を敷設するため、安定した高速なネットワークで接続できます。

📍 Direct Connect ロケーション

オンプレミスとAWSのデータセンターを相互接続するポイント。各リージョンに複数あり、接続先を選択できる。

🔚 Direct Connect エンドポイント

Direct Connectサービスが提供する範囲にある終端のルーター。AWSプライベートネットワークへの接続を保証する。

AWS VPN

AWS VPN はインターネット回線上に仮想の専用線（VPNトンネル）を張り、暗号化通信を行うサービスです。 専用回線を敷設するDirect Connectよりも安価かつ短期間で接続を開始できます。

💻 AWS クライアント VPN

PCなどの端末とVPCのクライアントVPNエンドポイントをインターネットVPNで接続。OpenVPNを利用し、Windows / macOS / iOS / Android に対応。機器導入不要。

🏢 AWS Site-to-Site VPN

オンプレミスのカスタマーゲートウェイとVPCの仮想プライベートゲートウェイを接続。IPsecで通信を保護する。

🔶 試験のポイント（CLF / SAA 頻出）
  • Direct Connect＝専用回線。高帯域・安定・低遅延が必要なら選択（開通に時間とコスト）
  • AWS VPN＝インターネット上の暗号化トンネル。安価・短期間で開始できる
  • クライアントVPN＝端末↔VPC、Site-to-Site VPN＝拠点↔VPC
  • 「より安全で安定した専用接続 → Direct Connect」「手軽に暗号化接続 → VPN」
