🛡 AWS WAF / AWS Shield CLF

不特定多数のユーザーがアクセスするWebサービスには、インターネットからの攻撃に対して保護が必要です。AWSでは、AWSリソースを保護するためのサービスとして「AWS WAF」と「AWS Shield」が提供されています。どちらもマネージド型のサービスです。

AWS WAF（Web Application Firewall）

AWS WAF（Web Application Firewall）は、脆弱性を狙った外部からの攻撃や不正アクセスから、WebアプリケーションをWeb ACLで保護するサービスです。

🚫 防御できる攻撃
  • SQLインジェクション: 悪意のあるSQLを送り込んで情報を盗み出す攻撃
  • XSS（クロスサイトスクリプティング）: 悪意のあるスクリプトをWebフォームに埋め込む攻撃
  • 特定の国からのアクセスを全てブロック（地理的一致ルール）
  • 短時間に異常に多くのリクエストを送ってくるIPを自動的にブロック（レートベースのルール）
⚙️ Web ACL（アクセス制御リスト）

ユーザーは「Web ACL」と呼ばれるアクセス制御リストで、訪問者のIPアドレスや、ウェブページへのリクエスト内容（例：HTTPヘッダー、HTTP本文、ウェブページのアドレスなど）に基づいて、どのようなアクセスを許可し、どのようなアクセスを遮断するかを細かく決めることができます。

🔗 アタッチ先サービス
  • Amazon CloudFront
  • Application Load Balancer（ALB）
  • Amazon API Gateway

AWS Shield（DDoS対策）

AWS Shieldは、DDoS攻撃からの保護に特化したサービスです。DDoS攻撃とは、Webサイトやサーバーに大量のアクセスを送り込むことで、サービスを停止させる攻撃のことです。

🆓 AWS Shield Standard（無料）

ネットワーク層およびトランスポート層への一般的なDDoS攻撃からAWSリソースを保護します。デフォルトで有効になっています。すべてのAWSユーザーが無料で利用できます。

💎 AWS Shield Advanced（有料）

EC2インスタンス、Elastic Load Balancing、Amazon CloudFrontなどを標的としたDDoS攻撃に対して、高度な保護サービスを利用できます。

  • 高度な大規模攻撃からの保護
  • DDoS攻撃発生時のモニタリングやレポート
  • AWSのDDoS対応チーム（DRT）によるサポート
  • 攻撃によって増加したAWS利用料金の補填

主な対象アプリ層攻撃（SQLi・XSS）ネットワーク/トランスポート層DDoS大規模・高度なDDoS
費用有料無料（自動有効）有料
カスタムルール◎ Web ACLで細かく制御✕◎

🔶 試験のポイント（CLF・SAA 頻出）
  • SQLインジェクション・XSS対策 → AWS WAF
  • DDoS対策 → AWS Shield（Standard は全ユーザー無料・自動有効）
  • Shield Advancedは有料だが、攻撃による追加コストの補填もある
  • WAFはCloudFront・ALB・API Gatewayにアタッチして使用
  • WAFとShieldは別サービスだが、組み合わせて使うことが多い（WAF=アプリ層、Shield=ネットワーク層）
