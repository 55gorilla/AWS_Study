🔑 AWS KMS / AWS CloudHSM SAA

AWSにおける暗号化キーの管理サービスです。 AWS KMSはAWSマネージドのキー管理、AWS CloudHSMはユーザー自身が管理するハードウェアセキュリティモジュールです。

AWS KMS（Key Management Service）

AWS KMSは、AWSが管理するHSM（Hardware Security Module）上で暗号化キーを作成・管理するマネージドサービスです。S3・RDS・EBS・DynamoDBなど多くのAWSサービスと統合されています。

🔑 KMSキー（CMK）

Customer Managed Key（顧客管理キー）またはAWS Managed Key（AWS管理キー）。暗号化・復号に使用する主要なキー。

📦 エンベロープ暗号化

データを暗号化するデータキーを、KMSキーでさらに暗号化する2層構造。大容量データを効率的に暗号化できる。

📋 CloudTrail連携

KMSキーの全使用操作がCloudTrailに記録される。誰がいつキーを使用したかの監査が可能。

🌐 マルチリージョンキー

複数リージョンで同じキーIDを使用できる機能。リージョン間での暗号化データの複製に便利。

AWS CloudHSM

CloudHSMは、ユーザー専有のハードウェアセキュリティモジュール（HSM）をVPC内で実行するサービスです。キーのライフサイクル全体をユーザーが完全管理します。

🧭 どちらを選ぶ？ — KMS vs CloudHSM

🔑 AWS KMS

AWSがHSMを管理（マネージド）
AWSサービスとの統合が簡単
CloudTrailで監査ログ自動記録
一般的な暗号化ニーズ
マネージド AWS連携 簡単設定
VS

🏦 AWS CloudHSM

ユーザーが専有HSMを完全管理
FIPS 140-2/3レベル3準拠が必要
キーをAWSと共有したくない
厳格なコンプライアンス要件
専有HSM FIPS準拠 完全制御
🔶 試験のポイント（SAA 頻出）
  • KMS = AWSマネージドのキー管理、多くのAWSサービスと自動統合
  • CloudHSM = ユーザーが専有HSMを完全管理、FIPS 140-2/3準拠
  • エンベロープ暗号化：データキー → KMSキーで暗号化する2層構造
  • KMSキーの使用はCloudTrailで全て監査可能
  • 「AWSとキーを共有したくない、厳格なコンプライアンス → CloudHSM」
  • RDS・S3・EBS・DynamoDB等の暗号化はKMSと連携
