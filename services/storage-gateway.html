🔌 AWS Storage Gateway CLF SAA

AWS Storage Gateway は、オンプレミス環境とAWSクラウドストレージをシームレスに接続するハイブリッドストレージサービスです。 オンプレミスのアプリケーションから、AWSのS3やGlacierなどのストレージを、まるでローカルストレージのように利用できます。

Storage Gateway の全体像

オンプレミス側に「ゲートウェイ」（仮想アプライアンスまたは物理アプライアンス）を配置し、これを介してAWSストレージへアクセスします。頻繁にアクセスするデータはローカルにキャッシュされ、低レイテンシを実現します。

3種類のゲートウェイタイプ

📁 ファイルゲートウェイ（S3 File Gateway）

NFS / SMBプロトコルでファイルとしてアクセス。ファイルはS3オブジェクトとして保存される。

用途：ファイルサーバーのクラウド化、バックアップ

💾 ボリュームゲートウェイ（Volume Gateway）

iSCSIでブロックストレージとしてアクセス。スナップショットをS3に保存。

  • キャッシュ型：データの実体はS3、頻繁アクセス分のみローカルキャッシュ
  • 保存型：データの実体はオンプレミス、S3に非同期バックアップ
📼 テープゲートウェイ（Tape Gateway）

仮想テープライブラリ（VTL）として動作。既存のバックアップソフトをそのまま使い、S3 / S3 Glacierへアーカイブ。

用途：物理テープからの移行、長期アーカイブ

ゲートウェイタイプ比較

タイププロトコルデータ形式主な用途
ファイルゲートウェイNFS / SMBS3オブジェクトファイル共有・バックアップ
ボリュームゲートウェイiSCSIEBSスナップショットブロックストレージ・DR
テープゲートウェイiSCSI VTL仮想テープ→Glacier長期アーカイブ・テープ置換
🔶 試験のポイント（SAA 頻出）
  • 「オンプレミスからS3にアクセス → Storage Gateway」
  • ファイルゲートウェイ = NFS/SMB（ファイル共有）
  • ボリュームゲートウェイ = iSCSI（ブロック）、キャッシュ型と保存型がある
  • テープゲートウェイ = 既存バックアップソフトで仮想テープ → Glacierアーカイブ
  • 頻繁にアクセスするデータはローカルキャッシュで低レイテンシ
  • 「物理テープ運用をクラウドに移行 → テープゲートウェイ」
