📦 AWS Batch SAA

AWS Batch は、大規模なバッチコンピューティングジョブを自動的に実行・スケーリングするフルマネージドサービスです。 ジョブの数や要件に応じて、最適なコンピューティングリソース（EC2/Fargate/スポット）を自動的にプロビジョニングします。

AWS Batch の概要

ジョブキューに投入されたジョブを、AWS Batchが自動的にスケジューリングし、必要なコンピューティング環境を用意して実行します。完了するとリソースは自動的に縮小されます。

🔶 試験のポイント（SAA）
  • 「大規模なバッチ処理を自動実行・スケーリング → AWS Batch」
  • ジョブキュー・ジョブ定義・コンピューティング環境で構成
  • スポットインスタンスを使ってコスト最適化が可能
  • 科学計算・データ分析・レンダリング・ETL処理などに利用
  • Lambda（15分制限）では足りない長時間バッチに適する
