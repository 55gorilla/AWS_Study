🔧 AWS Glue SAA

AWS Glue は、フルマネージドの ETL（Extract / Transform / Load）サービスです。 複数のデータソースからデータを抽出し、統合・変換して対象へ展開する、データ分析の「橋渡し」の役割を担います。

ETL とは

ETL は、データの抽出（Extract）・変換（Transform）・ロード（Load）を意味します。複数のデータソースからデータを抽出し、統合・変換したデータを蓄積する一連のプロセスです。Glue はこの ETL を代表するAWSサービスです。

主な構成要素

🗂 データカタログ

ファイルのスキーマ（列名・データ型・フォーマット）などのメタデータを保存。Athena など他サービスから参照できる。

🕷 クローラー

データソースを走査してスキーマを自動推論し、データカタログに登録する。

⚙️ Glue ジョブ

カタログを基にETLエンジンとして動作。Apache Spark 上で実行され、Python / Scala のスクリプトが自動生成される（編集可）。

対応形式：CSV・XML・JSON・Parquet など多様。データソースは S3 や Kinesis Data Streams など、出力先は Redshift などを選べます。

🔶 試験のポイント（SAA 頻出）
  • 「サーバーレスのETL／データカタログ → AWS Glue」
  • クローラーでスキーマを自動検出 → Athena でSQL分析、という連携が頻出
  • Glue ジョブは Apache Spark で実行（Python / Scala）
