💡 試験でよく出る「どちらのサービスを使うか」の判断基準を一覧にまとめました。

ストレージ比較

判断基準→ 選ぶべきサービス
静的ファイル・バックアップ・HTTP配信🪣 Amazon S3
EC2のOSドライブ・DBボリューム（1インスタンス専用）💿 Amazon EBS
複数EC2で同じファイルを共有（NFS）📁 Amazon EFS
オンプレミスのアプリからS3/EBSにアクセス🔌 AWS Storage Gateway

データベース比較

判断基準→ 選ぶべきサービス
SQL・トランザクション（ACID）・JOIN が必要🗃 Amazon RDS
超高速（ミリ秒以下）・スケール・スキーマレス📊 Amazon DynamoDB
MySQL/PostgreSQL互換でRDSより高パフォーマンス✨ Amazon Aurora
PB級データの分析・データウェアハウス📉 Amazon Redshift
DBのクエリ結果をキャッシュして高速化⚡ Amazon ElastiCache

コンピューティング比較

判断基準→ 選ぶべきサービス
OSレベルの管理が必要・長時間実行🖥 Amazon EC2
イベント駆動・サーバーレス・15分以内⚡ AWS Lambda
Dockerコンテナ・AWS管理オーケストレーション📦 Amazon ECS + Fargate
Kubernetes・フルコントロール☸️ Amazon EKS

ネットワーク・セキュリティ比較

判断基準→ 選ぶべきサービス
HTTP/HTTPSの高度なルーティング（パス/ホストベース）🌐 ALB
TCP/UDPの超低レイテンシ・固定IP⚡ NLB
グローバルトラフィック最適化・固定AnycastIP🌐 Global Accelerator
SQLインジェクション・XSS・ボット対策🛡 AWS WAF
DDoS攻撃からの保護🛡 AWS Shield

監視・ログ比較

判断基準→ 選ぶべきサービス
CPU使用率・メモリ等のパフォーマンス監視📈 CloudWatch
誰がいつ何の操作をしたか（API監査）🔍 CloudTrail
AWSベストプラクティスとの乖離チェック💡 Trusted Advisor
過去コストの可視化・将来予測💰 Cost Explorer
予算超過アラート設定💰 AWS Budgets
アプリの分散トレーシング（遅延/エラー箇所特定）🩻 AWS X-Ray

アプリケーション統合 比較

判断基準→ 選ぶべきサービス
1メッセージを複数の宛先へ同時配信（プッシュ/ファンアウト）📣 Amazon SNS
処理を非同期で受け渡し・急増を吸収（プル型キュー）📨 Amazon SQS
状態変化やスケジュールを契機に処理を起動（イベント）🔔 EventBridge
複数サービスを順序立てて連携・オーケストレーション🔀 Step Functions

データ分析 比較

判断基準→ 選ぶべきサービス
ストリーミングデータを収集・一時保持🌊 Kinesis Data Streams
ストリームをS3/Redshift/OpenSearchへ配信🚒 Data Firehose
サーバーレスのETL・データカタログ🔧 AWS Glue
S3上のデータをサーバーレスでSQL分析🔎 Amazon Athena
PB級データのDWH分析📉 Amazon Redshift
ダッシュボード・BI可視化📊 Amazon QuickSight

セキュリティ検出 比較

判断基準→ 選ぶべきサービス
S3内の機密データ（個人情報/PII）を検出・分類🔍 Amazon Macie
不正アクセス・脅威の継続的な検知🐶 Amazon GuardDuty
EC2/コンテナ等の脆弱性スキャン🩺 Amazon Inspector
各種セキュリティ結果を集約・一元管理🗂 Security Hub

認証・アイデンティティ 比較

判断基準→ 選ぶべきサービス
AWSリソースへの認証・認可（人/サービスの権限）🔐 IAM
複数AWSアカウント/SaaSへのSSO一元管理🪪 IAM Identity Center
アプリ利用者（数百万人）のサインイン👤 Amazon Cognito
一時的な認証情報の発行（AssumeRole/クロスアカウント）🎟 AWS STS

移行・転送 比較

判断基準→ 選ぶべきサービス
オンライン高速転送・継続同期（NFS/SMB→S3/EFS/FSx）🔄 AWS DataSync
大容量データを物理デバイスでオフライン移行❄️ AWS Snowball
オンプレ常時接続でAWSストレージを利用🔌 Storage Gateway
DBの移行（異種DBエンジン間も可・CDC）🗃 DMS
サーバー全体のリフト&シフト移行🖥 MGN

🛡 セキュリティ最小権限・多層防御・暗号化・トレーサビリティ
🔁 信頼性自動復旧・水平スケール・単一障害点の排除・疎結合
⚡ パフォーマンス効率サーバーレス・グローバル展開・キャッシュ・CDN
💰 コスト最適化従量課金・適切なサイジング・未使用停止・可視化
🛠 運用上の優秀性運用のコード化(IaC)・小さく頻繁な変更・障害から学ぶ
🌱 持続可能性環境負荷の最小化・リソース効率の継続改善
